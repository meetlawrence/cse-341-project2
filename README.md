# Personal Expense Tracker API

A simple and efficient RESTful API designed to help users manage their daily finances. This project utilizes MongoDB's flexible document schema to store expense logs and leverages its powerful aggregation pipeline to dynamically calculate spending totals by category.

## Core Features
* **Full CRUD Functionality:** Create, read, update, and delete expense records.
* **Smart Filtering:** Retrieve expenses sorted by date or filtered by specific categories.
* **Data Insights:** Advanced MongoDB aggregation endpoints to calculate total spending breakdowns.
